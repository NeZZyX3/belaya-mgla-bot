# Бот для «Белая мгла: выживание» (русская версия Whiteout Survival)

Сборка на основе [Autopilot](https://github.com/batazor/autopilot) (лицензия MIT) с правками для русского клиента `com.gof.globalru`.
Образ бота собирается **поверх официального образа автора**, поэтому его обновления подтягиваются автоматически (ежедневная сборка), а здесь лежат только русские исправления.

> ⚠️ Автоматизация игры почти наверняка нарушает правила игры и может привести к бану аккаунта. Используете на свой риск.

## Установка (Windows)

1. Установите **Docker Desktop** (с WSL2). Settings → Resources → Network → включите **Enable host networking** → Apply & restart.
2. Установите **BlueStacks 5**. Настройки:
   - Экран: **вертикальный режим, 720×1280, 320 DPI**;
   - Производительность: 2 ядра, 2 ГБ ОЗУ, 30 FPS;
   - Дополнительно: **Android Debug Bridge — включён**.
3. Установите игру, войдите в аккаунт. В графике игры отключите снегопад и смену дня и ночи, не ставьте «Ультра».
4. Скачайте [`ru/deploy/install.bat`](https://raw.githubusercontent.com/NeZZyX3/belaya-mgla-bot/main/ru/deploy/install.bat) (ПКМ → «Сохранить как…») и запустите. Откроется панель `http://127.0.0.1:3000`.
5. В панели: **ADB → Register 127.0.0.1:5555**, затем в таблице устройства выберите **Capture = adb** и **Input = adb** (scrcpy роняет BlueStacks).
6. На странице **Click approvals** выключите **Approval mode**, если бот должен работать без подтверждения каждого нажатия.

> Не нажимайте **Start bot** в мастере настройки: бот уже работает в своём контейнере, кнопка запускает второй экземпляр, и они мешают друг другу.

Обновление — просто запустите `install.bat` ещё раз (настройки и зарегистрированные устройства сохраняются).
Скриншоты, которые видит бот, лежат в `%USERPROFILE%\autopilot\captures`.

## Что исправлено относительно оригинала

| Проблема | Исправление |
|---|---|
| ADB-сервер внутри Docker на Windows зависал при старте, бот не видел эмулятор | `ru/runtime/adb` — сервер запускается в режиме `nodaemon` |
| Ошибки Redis `Cannot enable maintenance notifications…` ломали планировщик | `ru/runtime/belaya_redis_compat.py` |
| Бот не узнавал аккаунт: в русском профиле блок с ID выше на 45 px | `ru/overlay/games/wos/ru/core/chief_profile` |
| Подсказки обучения ложно срабатывали на русских экранах | модуль onboarding отключён для RU (`ru/overlay/.../onboarding`) |
| Бот иногда читал русский текст английской моделью OCR и не узнавал экраны | `ru/runtime/belaya_force_catalog.py` — всегда режим `wos_ru` |
| Рекламные окна с покупками при входе (например «Набор «Ночь…»») блокировали бота | модуль `ru/overlay/games/wos/ru/ads_promo` закрывает их крестиком (кнопку цены не трогает) |
| Окно «С возвращением!» (офлайн-доход) не закрывалось — бот стоял на нём при каждом входе | `ru/overlay/games/wos/ru/welcome_back_confirm` — видит русский заголовок и жмёт «Подтвердить» |

## Как помочь

Нашли экран, на котором бот застревает? Откройте issue и приложите скриншот из папки `captures` и время, когда это случилось.
